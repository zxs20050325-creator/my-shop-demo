# 第一章 软件概述

## 1.1 软件简介

冀遗筑梦 - 数字化非遗盲盒平台 V8.2（以下简称"本软件"或"平台"）是一款面向河北省非物质文化遗产（以下简称"非遗"）数字化展示与传播的网页端电商平台。平台以"非遗盲盒"为核心创意，将河北地区的历史古建筑、非遗技艺与传统手工艺进行数字化复刻，通过盲盒抽取、展品浏览、文化介绍、藏品收藏等交互形式，向用户提供兼具文化传播与数字收藏功能的体验式服务。

本软件以正定古城广惠寺华塔、赵州桥、承德避暑山庄、山海关、隆兴寺、清西陵等河北历史文化遗产为文化题材，设计了一系列以"盲盒"为载体的数字藏品，用户在抽取盲盒的过程中，逐步了解河北非遗文化背后的历史故事与技艺传承。

## 1.2 软件主要功能

本软件的功能体系由前台用户功能与后台管理功能两大部分组成，具体如下：

（一）前台用户功能

1. 非遗盲盒抽取功能：平台以"盲盒"形式向用户随机呈现数字藏品，用户点击盲盒卡片即可完成抽取，抽取结果包含不同稀有度等级的藏品。
2. 非遗展品浏览功能：平台提供数字藏品列表展示，用户可浏览全部已上架的非遗数字藏品，查看藏品图片、名称、价格、分类等信息。
3. 非遗文化介绍功能：平台首页以图文形式介绍河北古建筑的数字化复刻理念，配合侧边栏系列导航展示不同文化系列。
4. 藏品分类筛选功能：用户可通过侧边栏系列导航，按不同文化系列与品类对藏品进行筛选浏览。
5. 藏品搜索功能：用户可通过顶部搜索框输入关键词，对藏品进行检索。
6. 用户注册与登录功能：用户可注册平台账户，登录后使用收藏、购物车等个性化功能。
7. 购物车（选藏清单）功能：用户可将心仪藏品加入购物车，查看、移除或结算选中的藏品。
8. 收藏夹（我的收藏）功能：用户可收藏心仪藏品，并在收藏夹中集中查看与取消收藏。
9. 结算与确权（结缘确权）功能：用户对购物车中的藏品进行结算，选择确权方式并完成支付流程。

（二）后台管理功能

1. 管理员登录功能：后台管理入口设置管理员口令鉴权，仅授权管理员可进入。
2. 数据总览功能：以关键指标卡片与图表形式展示平台运营数据，包括总营收、访问量、成交订单、活跃用户等核心指标。
3. 商品管理功能：支持对数字藏品进行新增、编辑、删除、上架、下架操作。
4. 订单管理功能：展示全部交易订单明细，支持订单数据导出。
5. 用户管理功能：展示全部注册用户列表及其购物车、收藏、最近活动等信息。
6. 实时交互日志功能：实时记录并展示用户行为日志，支持日志数据导出。

## 1.3 软件技术特点

本软件采用前后端分离的架构设计，前端使用 HTML5、CSS3、JavaScript 及 Chart.js 图表库构建交互界面，后端使用 Node.js 与 Express 框架提供服务接口，数据存储使用 SQLite 轻量级数据库。软件具备以下技术特点：

1. 前后端分离架构：前端界面与后端服务接口相互独立，通过 HTTP 接口进行数据交互，便于部署与维护。
2. 用户行为追踪与分析：软件对用户的浏览、加购、支付、搜索等行为进行全程记录，并在后台进行统计分析与可视化展示。
3. 安全的密码存储机制：用户密码采用 scrypt 算法加盐哈希后存储，不保存明文密码，保障账户安全。
4. 实时数据可视化：后台管理使用 Chart.js 图表库，以折线图、柱状图、环形图等多种图表形式实时展示运营数据。
5. 轻量级本地部署：软件使用 SQLite 数据库，无需额外配置数据库服务，开箱即用，便于快速部署。

## 1.4 运行环境

本软件的运行环境要求如下：

1. 服务器端环境：Node.js 18.0 及以上版本，支持 node:sqlite 内置模块。
2. 操作系统：Windows、Linux、macOS 等主流操作系统。
3. 客户端环境：支持现代浏览器，推荐使用 Chrome、Edge、Firefox 等浏览器的最新版本。
4. 网络环境：需要网络连接以加载字体、图标及外部静态资源。

## 1.5 术语定义

为便于用户理解本手册，现对文中出现的专业术语作如下说明：

1. 盲盒：指在抽取前不公开具体内容的数字藏品包装形式，用户抽取后方可知晓所得藏品。
2. 数字藏品：指平台中以数字化形式呈现的非遗文化藏品，包含名称、图片、价格、分类等属性。
3. 稀有度：指数字藏品的稀缺程度标识，平台中以 SSR、R 等不同等级区分。
4. 选藏清单：指用户加入购物车的藏品集合，即"购物车"。
5. 结缘确权：指用户完成支付结算、确认获得藏品所有权的操作流程。
6. 主理人：平台对注册用户的称谓，对应"用户账户"的概念。
7. 连接密令：平台对用户密码的形象化称谓，即登录密码。

# 第二章 系统安装与启动

## 2.1 环境准备

在启动本软件之前，请确保服务器已安装 Node.js 运行环境（版本 18.0 及以上）。用户可通过在命令行执行以下命令检查 Node.js 版本：

```
node -v
```

如未安装 Node.js，请访问 Node.js 官方网站下载并安装对应操作系统的安装包，安装完成后重新执行上述命令确认版本。

## 2.2 数据库初始化

本软件使用 SQLite 数据库，数据库文件默认存放于软件后端目录下。软件首次启动时会自动创建所需的全部数据表，并自动写入默认的非遗数字藏品示例数据，无需用户手动初始化。

如使用 Supabase（PostgreSQL）作为数据库，需要在 Supabase 控制台的 SQL Editor 中依次执行以下脚本：

1. 执行 backend/supabase-init.sql 脚本，创建表结构。
2. 执行 backend/supabase-functions.sql 脚本，创建数据库函数（包含热销商品过滤逻辑）。

## 2.3 服务启动

按以下步骤启动本软件后端服务：

1. 进入软件后端目录（backend 目录）。
2. 安装项目依赖，执行命令：

```
npm install
```

3. 启动后端服务，执行命令：

```
npm start
```

服务启动成功后，命令行将输出提示信息，默认监听 3000 端口。

## 2.4 访问方式

服务启动后，用户可通过浏览器访问以下地址进入平台：

1. 前台商城首页：在浏览器地址栏输入 http://localhost:3000 ，系统将自动跳转至前台首页。
2. 后台管理入口：在浏览器地址栏输入 http://localhost:3000/admin ，进入后台管理登录界面。

# 第三章 前台用户操作指南

## 3.1 首页与非遗文化展示

### 3.1.1 功能说明

平台首页是用户进入系统后的第一个界面，承担非遗文化展示与商品入口的双重职能。首页顶部为功能导航栏，左侧为系列导航侧边栏，中部为文化展示巨幕与盲盒商品列表。

### 3.1.2 界面组成

首页界面由以下部分组成：

1. 顶部导航栏：位于页面顶部，包含搜索框、购物车入口、登录/注册入口三个功能组件。
2. 系列导航侧边栏：位于页面左侧，包含"冀遗筑梦"品牌标识，以及"正定华塔""避暑山庄""赵州古桥""史诗典藏"四个系列导航节点。
3. 文化展示巨幕（Hero 区）：位于页面主体上部，以正定广惠寺华塔为主题大图，配以"以广惠寺华塔为例：将河北古建筑数字化复刻"的文化介绍文字，以及"揭开全系列惊喜"按钮。
4. 盲盒商品列表：位于页面主体下部，以三列网格形式展示数字藏品盲盒卡片。

### 3.1.3 操作步骤

1. 用户在浏览器中访问平台地址，进入首页。
2. 用户可阅读文化展示巨幕中的非遗文化介绍文字，了解平台的数字化复刻理念。
3. 用户可点击"揭开全系列惊喜"按钮，页面将自动平滑滚动至下方商品列表区域。
4. 用户可将鼠标悬停在盲盒卡片上，卡片将呈现高亮与位移动效。

## 3.2 用户注册

### 3.2.1 功能说明

新用户在使用购物车、收藏夹等个性化功能前，需先注册平台账户。注册功能通过独立的注册页面完成。

### 3.2.2 操作步骤

1. 在首页顶部导航栏点击"登录/注册"入口，或直接访问登录页并点击"还没有账户？立即注册"链接，进入注册页面。
2. 在注册页面中，用户需依次填写以下信息：
   - 用户名：用户自行设定的账户名称，用于登录与标识身份。
   - 密码：用户自行设定的登录密码。
   - 确认密码：再次输入相同密码，用于确认输入无误。
3. 用户填写完成后，点击"创建账户 / CREATE ACCOUNT"按钮提交注册。
4. 系统校验通过后，页面提示"注册成功"，并自动跳转至登录页面。

### 3.2.3 注意事项

1. 用户名必须填写，且不可与已注册用户重名。
2. 两次输入的密码必须一致，否则系统将提示"两次输入的密码不一致"。
3. 注册成功后请妥善保管账户信息。

## 3.3 用户登录（盲盒开盒式登录）

### 3.3.1 功能说明

本软件的用户登录页面采用独特的"盲盒开盒"仪式化设计。登录界面以星空、明月、古建筑剪影为背景，以盲盒礼盒为主视觉，用户输入账户信息后点击"开启盲盒"按钮完成登录，登录成功后礼盒将呈现开盒动画效果。

### 3.3.2 操作步骤

1. 在首页顶部导航栏点击"登录/注册"入口，进入登录页面。
2. 在登录页面中，用户需填写以下信息：
   - 主理人账号：即用户注册时填写的用户名。
   - 连接密令：即用户注册时设置的登录密码。
3. 用户填写完成后，点击"开启盲盒"按钮提交登录。
4. 系统校验通过后，礼盒将呈现盒盖掀开与光爆动画，随后自动跳转至首页。
5. 若用户名或密码错误，系统将提示"密令错误，无法开启盲盒"。

### 3.3.3 注意事项

1. 登录前需先完成账户注册。
2. 登录成功后，系统将自动从服务端同步该账户的购物车与收藏数据。

## 3.4 非遗盲盒抽取

### 3.4.1 功能说明

非遗盲盒抽取是本平台的核心特色功能。首页商品列表以盲盒卡片形式呈现，卡片正面隐藏藏品信息，仅显示"冀"字印章与编号，用户点击卡片后，卡片翻面揭晓所得藏品。

### 3.4.2 操作步骤

1. 在首页商品列表区域，用户可看到多个盲盒卡片，卡片正面显示"冀"字印章与藏品编号。
2. 用户点击任意盲盒卡片，卡片将触发翻面动画，正面隐藏，背面显示该藏品的真实图片、稀有度等级、名称与价格。
3. 揭晓的藏品信息包括：
   - 藏品图片：展示数字藏品的视觉形象。
   - 稀有度标签：显示藏品的稀有度等级（如 SSR、R）。
   - 藏品名称：显示藏品的具体名称。
   - 藏品价格：显示藏品的价格。
4. 用户可在卡片背面点击加号按钮，将揭晓的藏品加入购物车。

### 3.4.3 注意事项

1. 盲盒抽取结果以卡片翻面形式呈现，具有随机揭晓的仪式感。
2. 已揭晓的卡片将保持展开状态，用户可再次查看藏品信息。

## 3.8 购物车（选藏清单）

### 3.8.1 功能说明

购物车（平台内称为"选藏清单"）用于集中管理用户选中的数字藏品。用户可在购物车中查看、移除藏品，并对全部选中藏品进行结算。

### 3.8.3 注意事项

1. 结算前需确保已登录账户。

## 3.9 收藏夹（我的收藏）

### 3.9.1 功能说明

收藏夹功能用于集中管理用户收藏的数字藏品，用户可在此查看全部已收藏藏品，并可取消收藏。

### 3.9.2 操作步骤

1. 在页面侧边栏或导航栏点击"收藏夹"入口，进入我的收藏页面。
2. 在我的收藏页面中，用户可查看全部已收藏藏品，每条记录包含藏品图片、名称与价格信息。
3. 用户可点击藏品卡片上的"取消收藏"按钮，将对应藏品从收藏夹中移除。
4. 若收藏夹为空，页面将提示"您的收藏夹是空的"，并提供"去逛逛"按钮引导用户返回首页。

## 3.10 结算与确权（结缘确权）

### 3.10.1 功能说明

结缘确权功能用于完成对购物车中藏品的支付结算。用户在此页面确认藏品清单、选择确权方式并完成支付，支付成功后即完成藏品的"确权"。

### 3.10.2 操作步骤

1. 用户在选藏清单页面点击"带走它 / TAKE ME HOME"按钮，系统结算成功后跳转至结缘确权页面。
2. 在结缘确权页面中，用户可查看"结缘清单"摘要，确认待结算的藏品列表与金额。
3. 用户在"选择确权方式"区域选择支付方式，可选方式包括：
   - 微信结缘 / WeChat。
   - 数字货币 / Alipay。
4. 用户确认金额无误后，点击"确权并结缘 / SECURE & LINK"按钮提交支付。
5. 系统处理支付请求，支付成功后弹出"结缘成功"提示，用户点击"返回空间"按钮返回首页。

### 3.10.3 注意事项

1. 结算前需确保购物车中已有藏品。
2. 支付成功后，购物车将被清空，订单数据将记录至后台。

# 第五章 数据与安全说明

## 5.1 数据存储说明

本软件的数据存储采用 SQLite 数据库，数据库文件默认存放于软件后端目录下。软件涉及的数据表包括：

1. 用户表（users）：存储用户账户信息。
2. 商品表（products）：存储数字藏品信息。
3. 购物车表（carts）：存储用户的购物车数据。
4. 收藏表（favorites）：存储用户的收藏数据。
5. 行为日志表（user_logs）：存储用户行为记录。
6. 订单表（orders）：存储交易订单数据。

## 5.2 用户行为追踪说明

本软件对用户在平台上的关键操作进行全程追踪与记录，追踪的行为类型包括：

1. 浏览行为：记录用户浏览首页、浏览商品等操作。
2. 加购行为：记录用户将商品加入购物车的操作。
3. 支付行为：记录用户完成订单结算的操作。
4. 搜索行为：记录用户输入关键词进行搜索的操作。
5. 筛选行为：记录用户切换品类进行筛选的操作。

上述行为数据用于后台的统计分析，帮助管理员了解平台运营情况。

## 5.3 密码安全说明

本软件对用户密码采用加盐哈希的方式存储，使用 scrypt 算法对密码进行加密处理，数据库中不保存明文密码。用户登录时，系统将输入的密码进行同样的加密处理后与存储的哈希值比对，从而在保障账户安全的同时完成身份校验。

# 第六章 常见问题解答

## 6.1 无法启动服务怎么办？

请检查是否已正确安装 Node.js 运行环境，并确认已执行 npm install 完成依赖安装。若仍无法启动，请检查端口 3000 是否被占用。

## 6.2 忘记密码怎么办？

平台当前版本暂未提供密码找回功能，如忘记密码，建议重新注册新账户。

## 6.3 加入购物车时提示"请先登录"怎么办？

购物车功能需要登录账户后使用。请先完成注册与登录，再执行加入购物车操作。

## 6.4 首页图片无法显示怎么办？

请检查后端服务是否正常启动，以及图片资源文件是否完整存放于指定目录。图片缺失时，系统将显示占位提示。

## 6.5 后台管理无法进入怎么办？

请确认输入的管理员口令是否正确。若口令遗忘，可查看后端环境变量配置中的管理员口令设置。
