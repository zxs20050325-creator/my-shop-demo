# 源码清理排版操作步骤

> 目的：将源程序去除背景底色，统一为"白底黑字"，适合复制进 Word，满足软件著作权登记源程序补正要求（白底黑字、不带底色、连续前 30 页 + 连续后 30 页、每页不少于 50 行）。

---

## 一、源程序文件清单（建议提交顺序）

按以下顺序收集源程序文件，确保逻辑连贯、与申请表填报的源程序量相符：

| 序号 | 文件路径 | 说明 |

| 3 | frontend/index.html | 前台首页（盲盒抽取、文化展示） |

## 二、第一步：去除语法高亮与背景底色

源程序在代码编辑器（VS Code 等）中打开时，通常带有语法高亮（彩色文字）和背景底色，需要先去除，否则复制进 Word 后会带底色。

**方法 A：在 VS Code 中以纯文本方式复制（推荐）**

1. 用 VS Code 打开源程序文件。
2. 按 `Ctrl + Shift + P` 打开命令面板，输入并选择 "Show Whitespace" 可关闭（可选）。
3. 关键一步：将语言模式切换为纯文本，避免高亮——
   - 点击右下角语言模式（如 "HTML"、"JavaScript"），在弹出列表中选择 "Plain Text（纯文本）"。
   - 此时代码将全部变为单一颜色（黑字白底）。
4. 按 `Ctrl + A` 全选，按 `Ctrl + C` 复制。
5. 粘贴到 Word 时使用"只保留文本"方式（见第三步），即可得到白底黑字的纯文本代码。

**方法 B：使用记事本中转**

1. 打开"记事本"程序。
2. 用记事本打开源程序文件（或把代码粘贴进记事本）。
3. 记事本本身即为纯文本、白底黑字，会自动去除一切颜色与背景。
4. 从记事本中 `Ctrl + A` 全选、`Ctrl + C` 复制，再粘贴进 Word。

**方法 C：批量去底色（若已经粘贴进 Word 且带底色）**

1. 在 Word 中全选代码（`Ctrl + A`）。
2. 点击"开始"选项卡 → "字体颜色" → 选择"黑色"。
3. 点击"段落"区域 → "底纹"（油漆桶图标）→ 选择"无颜色"。
4. 若仍有残留底色，可选中全文后，点击"清除所有格式"（橡皮擦图标），再重新设置字体。

---

## 三、第二步：导入 Word 并统一格式

1. 新建一个空白的 Word 文档。
2. 粘贴时选择"只保留文本"（右键 → 粘贴选项 → 只保留文本；或在"开始"→"粘贴"下拉中选择"只保留文本"）。这一步可确保不带任何底色和格式。
3. 全文统一设置格式（见下表）。

**推荐的 Word 格式设置**

| 项目 | 设置值 |
| --- | --- |
| 字体 | 宋体 或 等宽字体（如 Courier New、Consolas） |
| 字号 | 小五号（9 磅） |
| 字体颜色 | 黑色 |
| 背景/底纹 | 无（白色） |
| 段落行距 | 单倍行距（或固定值 12 磅） |
| 页边距 | 上、下、左、右各 1.5 厘米 |
| 对齐方式 | 左对齐 |
| 首行缩进 | 无 |

> 说明：源程序补正通常要求"每页不少于 50 行"。使用"小五号字 + 单倍行距 + 1.5 厘米页边距"的紧凑排版，每页可容纳约 50 行以上，满足要求。

---

## 四、第三步：添加页码与页眉

1. 点击"插入"选项卡 → "页码" → 选择页面底部居中。
2. 建议在页眉添加软件名称与版本号，如：冀遗筑梦 - 数字化非遗盲盒平台 V8.2 源程序。
3. 在源程序开头添加一个封面说明（可选），注明软件全称、版本号、源程序总行数。

---

## 五、第四步：确保前后 30 页连续

1. 源程序整理完成后，导出为 PDF（文件 → 另存为 → 选择 PDF 格式）。
2. 确认 PDF 总页数。若总页数不足 60 页，则整份提交；若超过 60 页，则需拆分：
   - 取"连续前 30 页"（第 1–30 页）。
   - 取"连续后 30 页"（倒数第 30 页至最后一页）。
3. 使用 PDF 拆分工具（如 Adobe Acrobat、WPS PDF 工具）分别导出前 30 页与后 30 页，作为提交材料。
